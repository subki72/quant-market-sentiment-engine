# Contributing to Quant Market Sentiment Engine

We welcome contributions that uphold production engineering standards.

## Local Setup

```bash
git clone https://github.com/subki72/quant-market-sentiment-engine.git
cd quant-market-sentiment-engine
make install
```

## Verification Before PR

```bash
make test
make lint
```

## Pre-Commit Hooks

```bash
pip install pre-commit
pre-commit install
```
